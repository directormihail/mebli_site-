# Dzhuran Office Furniture

Навчальний корпоративний портал для лабораторної роботи №3 з теми WEB-технологій та
інформаційних систем масового обслуговування.

## Що є в проєкті

- `index.html` - головна сторінка з презентацією підприємства.
- `products.html` - сторінка з товарами та послугами підприємства з випуску офісних меблів.
- `styles.css` - адаптивний дизайн без зовнішніх бібліотек.
- `script.js` - мобільне меню, демонстраційна форма заявки та інтерактивний підбір комплектації.

## Як переглянути сайт

Відкрийте файл `index.html` у браузері або опублікуйте всі файли на будь-якому статичному
хостингу. Для здачі у Wix/uCoz дизайн і тексти можна перенести в конструктор сторінок.

## Важливо перед здачею

У футері вже замінено стандартний копірайт на навчальний формат:

`Dzhuran Office Furniture © 2026_Джуран Михайло Богданович_051_ЕП-301д`

У футері використано українське написання групи `ЕП-301д` та код спеціальності `051`.
